软宝宝帮助已有软件项目的开发者、企业团队和代理机构整理软著申请材料。您可以上传项目文件夹或 ZIP，生成源代码文档；也可以结合软件截图，生成使用手册和设计文档。

[开始生成代码文档](https://rzcode.vip/) · [先看操作步骤](/rzcodedocs/docs/quick_guides/how_sourcecodedocs/)

## 我需要哪一种文档？

| 您要完成的工作 | 对应功能 | 使用方式 |
| --- | --- | --- |
| 将项目源码整理成 Word 文档 | 基础代码文档生成 | 免费，支持文件夹和 ZIP 上传 |
| 优先整理核心业务代码 | 进阶源代码文档 | 付费，分析项目并筛选内容 |
| 说明软件界面和操作流程 | 软件使用手册 | 付费，结合代码信息与软件截图生成 |
| 说明系统结构和模块设计 | 软件设计文档 | 付费，结合项目分析、章节和设计图生成 |
| 保存软著申请相关信息 | 申请信息表留档 | 付费，方便后续核对与使用 |

各项功能的计费方式见[定价与计费规则](/rzcodedocs/docs/concepts/pricing/00_overall/)。具体费用取决于所选功能及任务规模。

## 从真实项目开始整理

### 1. 准备代码和项目名称

准备您有权使用的项目源码，填写软件名称和版本号。网页支持上传本地文件夹或 ZIP 压缩包。上传前检查目录，避免将密钥、个人数据或与文档无关的文件一并提交。

### 2. 检查代码筛选结果

系统识别项目中的代码文件，并辅助过滤依赖、构建产物等内容。生成前仍需核对文件范围，确认核心功能对应的代码没有遗漏。详细步骤见[源代码文档生成教程](/rzcodedocs/docs/quick_guides/how_sourcecodedocs/)。

### 3. 按需补充截图或设计图

使用手册需要说明用户如何操作软件。准备能够展示主要功能和操作顺序的真实截图，有助于核对生成内容。设计文档则围绕架构和模块展开，可上传已有设计图，或使用平台提供的设计图生成功能。

### 4. 下载并核对材料

检查文档中的软件名称、版本号、功能描述、图片和代码是否对应同一项目。自动生成内容可能存在遗漏或错误，应根据软件实际情况修改后再使用。

## 不方便上传源码怎么办？

可以了解[本地协作模式](/rzcodedocs/docs/concepts/local-cooperate/)。该流程由本地 Agent 分析代码，再向软宝宝提交结构化分析结果；截图及文档生成仍可能涉及云端处理。

本地协作不等于完全离线。Agent 使用的模型服务如何处理数据，取决于您的配置。开始前应核对上传内容和所使用服务的数据处理方式。

## 免费功能与付费功能如何选择？

仅需整理源代码文档时，可以先使用免费的基础功能。需要软件操作说明时，查看[软件使用手册计费规则](/rzcodedocs/docs/concepts/pricing/02_software-manual/)；需要系统设计材料时，查看[设计文档计费规则](/rzcodedocs/docs/concepts/pricing/04_design-document/)。

## 常见问题

### 还没有软件项目，可以直接生成材料吗？

本工具围绕已有项目的代码和截图整理材料。请先准备真实的软件项目，再选择所需的文档功能。

### 使用手册和设计文档有什么区别？

使用手册主要说明用户如何使用软件；设计文档主要说明系统如何组织和实现。应根据实际需要选择，生成后都要核对内容。

### 生成后是否保证登记通过？

不保证。软宝宝提供材料整理和文档生成能力，用户仍需确认内容真实、准确、完整，并核对提交时的要求。
