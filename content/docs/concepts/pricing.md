# RZCode 定价方案

本文为公开定价说明，适用于 RZCode 的 credits 购买与文档生成计费。

## 1. 充值价格

- 0.99 元 = 1 credit

## 2. 计费范围

- 生成源代码文档：免费
- 生成软件使用手册（DOCX）：按 credits 计费
- 生成设计文档（DOCX）：按 credits 计费
- 生成帮助填写软著的文档：0.1~0.4 credits

## 3. 审校与排版计费

无论是软件使用手册还是设计文档，在章节内容合并为最终 Markdown 后，都会执行一次 Markdown 审校步骤，包括：

- 文字审校
- 噪音清理（代码块标记、JSON 调试信息、思考过程等）
- 章节结构检查与修正
- 图片排版优化：调整图片格式、生成题注、调整多图并排布局

**Markdown 审校固定费用：1.1 credits / 次**

## 4. 「软件使用手册」计费规则

软件使用手册生成按任务消耗 credits，计费由三部分组成：

### Step 1：截图预处理

- 每张截图消耗 0.1 credits

### Step 2：截图与代码校对

**Step 2.1: 预扫描步骤**

分析总结代码的内容和模块，提取关键信息：

- 当代码文件数量 <= 3000 时，0.1 credits
- 当代码文件数量 > 3000 时，0.2 credits

**Step 2.2: 截图校对**

按项目代码文件总数分档计费（单位：credits / 张截图）：

| 代码文件数 | 单价   |
| ---------- | ------ |
| <= 500     | 0.3    |
| 501-1000   | 0.5    |
| 1001-3000  | 0.7    |
| 3001-6000  | 0.9    |
| 6001-10000 | 1.0    |
| > 10000    | 不支持 |

### Step 3：文档内容生成

- 0.3 credits / 章节

章节计数口径：

- 顶层说明章节按章节数计费
- 功能章节按二级子章节数计费

### Step 4: 成文审校

- 1.1 credits / 全文
- 包括文字审校、噪音清理、结构检查与图片排版

## 5. 「设计文档」计费规则

设计文档生成按任务消耗 credits，计费由以下四部分组成：

### Step 1：推荐章节与设计图

- 0.5 credits / 次
- 一次性费用，推荐结果会持久化到项目，可复用

### Step 2：自动生成设计图

- 0.9 credits / 张
- 仅当选择由云端自动生成设计图时计费
- 用户自行上传的设计图不额外收费

### Step 3：章节生成

- 需要扫描代码的章节：0.4 credits / 章
- 不需要扫描代码的章节：0.2 credits / 章

### Step 4：成文审校

- 1.1 credits / 全文
- 包括文字审校、噪音清理、结构检查与图片排版

## 6. 计费示例

### 6.1 使用手册计费示例

若一次任务包含：

- 18 张截图
- 代码文件数 <= 500
- 共 9 个计费章节

则预计消耗：

```text
(0.1 + 0.3) x 18 + 0.1 + 0.3 x 9 + 1.1 = 12 credits
```

其中 1.1 credits 为合并后 Markdown 审校（含图片排版与题注）费用。

### 6.2 「设计文档」计费示例

若一次任务包含：

- 推荐章节与设计图 1 次
- 自动生成 6 张设计图
- 共 11 个章节

则预计消耗：

```text
0.5 + 0.9 x 6 + 0.4 x 11 + 1.1 = 11.4 credits
```

其中 1.1 为成文审校费用。

## 7. 使用限制

- 单个项目最多上传 50 张截图。可通过[企微联系客服](https://rzcode.vip/contact)，提升单个项目上限。
- 当前暂不支持代码文件数超过 10000 的项目。

- 定价策略可能根据产品升级进行调整，调整后将提前公示
