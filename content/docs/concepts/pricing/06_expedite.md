# 软著加急通道定价说明

软宝宝为已有真实项目代码并希望加快软件著作权申请进度的客户提供加急通道服务。

## 1. 价格构成

单次加急费用：

- 统一为：**￥670.00 / 次**
- 其中：
  - **￥600.00**：官费
  - **￥70.00**：渠道费和服务费

即：

```text
670 = 600（官费） + 70（服务费）
```

## 2. 适用场景

适用于以下客户：

- 已经具备真实项目代码与材料
- 希望缩短软件著作权申请审核周期
- 需要在较短时间内完成提交和后续跟踪

## 3. 费用说明

- 该费用为单次加急服务费用
- 适用于客户已有材料且无需发票的场景
- 如需重新生成材料或补充额外人工服务，不包含在该加急费用中
- 申请材料仍需符合版权保护中心的正式要求，材料不合格时仍可能出现补正或驳回
- 同一软著申请，补正提交不再额外收取费用

## 4. 相关说明

- 加急通道用于提高流程优先级，不改变官方审核标准
- 申请材料是否通过仍以官方审核结果为准
- 若需使用加急通道，请在项目页面中发起支付并跟踪状态
