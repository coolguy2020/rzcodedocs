# 软件使用手册计费规则

软件使用手册生成按任务消耗 credits，计费由四部分组成：

## 计费规则

### Step 1：截图预处理

- 每张截图消耗 0.1 credits

### Step 2：截图与代码校对

**Step 2.1: 预扫描步骤**

分析总结代码的内容和模块，提取关键信息：

- 当代码文件数量 <= 3000 时，0.1 credits
- 当代码文件数量 > 3000 时，0.2 credits

**Step 2.2: 截图校对**

按项目代码文件总数分档计费（单位：credits / 张截图）：

| 代码文件数 | 单价   |
| ---------- | ------ |
| <= 500     | 0.3    |
| 501-1000   | 0.5    |
| 1001-3000  | 0.7    |
| 3001-6000  | 0.9    |
| 6001-10000 | 1.0    |
| > 10000    | 不支持 |

### Step 3：文档内容生成

- 0.3 credits / 章节

章节计数口径：

- 顶层说明章节按章节数计费
- 功能章节按二级子章节数计费

### Step 4：成文审校

- 1.1 credits / 全文
- 包括文字审校、噪音清理、结构检查与图片排版

## 计费示例

若一次任务包含：

- 18 张截图
- 代码文件数 <= 500
- 共 9 个计费章节

则预计消耗：

```text
(0.1 + 0.3) x 18 + 0.1 + 0.3 x 9 + 1.1 = 11.1 credits
```

其中 1.1 credits 为合并后 Markdown 审校（含图片排版与题注）费用。
