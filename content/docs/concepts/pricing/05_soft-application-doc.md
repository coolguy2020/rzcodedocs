# 帮助填写软著文档计费规则

帮助填写软著的文档生成按任务复杂度计费，常见区间为 0.1~0.4 credits。

## 计费规则

帮助填写软著文档生成实际分为两步：先分析项目代码并提取关键信息，再生成申请表数据与 DOCX 文档。因此计费由以下两部分组成：

### Step 1：代码信息分析与提取

- 0.1 credits / 次
- 主要用于扫描项目源码、提取与软著申请表相关的信息
- 若项目为本地模式且已提供完整的源码元信息，可直接复用，不重复额外收费

### Step 2：生成申请表数据与文档

- 0.2 ~ 0.4 credits / 次
- 由 LLM 根据提取出的代码信息生成申请表内容，并输出最终文档
- 费用会随文档内容长度、章节复杂度和生成结果完整度变化而调整

### 计费说明

- 需要首次扫描源码的项目，通常按“分析 + 生成”两步计费
- 已经完成过代码信息提取、且直接复用已有结果的项目，通常只按生成文档部分计费
- 若任务重试或重复生成，按实际执行次数重新计费

## 计费示例

若一次任务需要先扫描项目源码，再生成完整申请表文档，则预计消耗：

```text
0.1 + 0.3 = 0.4 credits
```

若项目已提供完整源码元信息，且仅需生成申请表文档，则预计消耗：

```text
0.3 credits
```
