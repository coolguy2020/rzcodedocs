# 设计文档计费规则

设计文档生成按任务消耗 credits，计费由以下四部分组成：

## 计费规则

### Step 0：代码信息分析与提取

仅针对云端项目，不重复执行。0.5 ~ 0.9 credits

### Step 1：推荐章节与设计图

- 1.5 credits / 次
- 一次性费用，推荐结果会持久化到项目，可复用

### Step 2：自动生成设计图

- 1.6 credits / 张
- 仅当选择由云端自动生成设计图时计费
- 用户自行上传的设计图不额外收费

### Step 3：章节生成

- 0.6 credits / 章

### Step 4：成文审校

- 1.5 credits / 全文
- 包括文字审校、去AI味、噪音清理、结构检查与图片排版等

## 计费示例

若一次任务包含：

- 推荐章节与设计图 1 次
- 自动生成 6 张设计图
- 共 11 个章节

则预计消耗：

```text
0.5 + 1.5 + 1.6 x 6 + 0.6 x 11 + 1.5 = 19.7 credits
```

其中 1.5 为成文审校费用。
