# RZCode 定价方案

本文为公开定价说明，适用于 RZCode 的 credits 购买与文档生成计费。为便于查看，按文档类型拆分为总览页和多个独立计费规则页。

## 1. 充值价格

- 0.99 元 = 1 credit

## 2. 计费范围

- 生成源代码文档：免费
- 进阶模式生成源代码文档：按 credits 计费
- 生成软件使用手册（含带截图和无截图模式）：按 credits 计费
- 生成设计文档（DOCX）：按 credits 计费
- 生成帮助填写软著的文档：按 credits 计费（含全局代码扫描 0.5 ~ 0.9 credits，文档生成 1.1 ~ 1.8 credits）

## 4. 全局代码扫描计费

扫描项目代码生成 source_code_meta 元信息，是使用手册、帮助填写软著文档等文档生成的前置步骤：

- 当代码文件数量 <= 3000 时，0.5 credits / 次
- 当代码文件数量 > 3000 时，0.9 credits / 次
- 已完成扫描的项目直接复用结果，不重复收费

## 5. 审校与排版计费

无论是软件使用手册还是设计文档，在章节内容合并为最终 Markdown 后，都会执行一次 Markdown 审校步骤，包括：

- 文字审校
- 噪音清理（代码块标记、JSON 调试信息、思考过程等）
- 章节结构检查与修正
- 图片排版优化：调整图片格式、生成题注、调整多图并排布局

**Markdown 审校固定费用：1.5 credits / 次**

## 6. 使用限制

- 单个项目最多上传 50 张截图。可通过[企微联系客服](https://rzcode.vip/contact)，提升单个项目上限。
- 当前暂不支持代码文件数超过 10000 的项目。
