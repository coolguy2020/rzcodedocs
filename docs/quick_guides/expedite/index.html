软著加急通道使用说明

  • Open in Claude
  • Open in Perplexity
  • Copy Markdown

如果你的项目已经基本成型，并且希望更快地推进软著申请，可以使用软宝宝的加急通道。

加急通道适用于以下场景：

  • 已经拥有真实项目代码和材料
  • 希望缩短软件著作权登记流程时间
  • 需要提高补正的通过率
  • 需要在项目内跟踪加急状态和材料上传情况

1. 费用说明#

单次加急服务价格为：

  • 价格：￥670.00 / 次
  • 组成：￥600.00 官费 + ￥70.00 渠道和服务费

说明：

  • 本价格适用于客户已有材料且不需要发票的场景，需要发票请走人工服务。
  • 如果需要重新生成材料，通常需要另行生成对应文档或服务，不包含在该加急费用内
  • 若材料存在问题，可能需要补正；补正更新的的材料需要自行准备，补正后新材料提交的服务已包含在加急费用中。

2. 风险提示#

  • 由于退款难度太大，加急的材料需要是真实可用的程序或软件，买的材料恕不能接，客服会安排直接退款。
  • 学校的软著申请步骤较多，需尽早安排，软宝宝仅可提供版权局的申请表和申请流水号用来提交学校的系统。
  • 其他学校服务（签章页盖章，验证码获取等）需要客户自行处理，软宝宝只对版权局需要的材料进行处理。
  • 只有特定情况可以退官费，详情请参阅 加急通道使用说明——补正与退款。
  • 服务费只有在材料不全，没有全部上传华代系统的时候可以全部退回，一旦上传不退渠道和服务费。官费退款可以联系客服。

3. 使用入口#

在登录后，用户可在对应项目页面中进入“加急通道”模块，进行以下操作：

  1. 查看项目是否已支付加急费
  2. 选择发起加急支付
  3. 复制或打开支付链接
  4. 完成支付后刷新订单状态
  5. 上传材料，包括：
  • 学校材料需要提供完整的大学名称（例如：清华大学等）
  • 源代码文档
  • 使用手册或设计文档，二选其一
  • 帮助填写软著文档
  1. 等待客服完成并上传材料，通过预审拿到流水号和签章页，下载签章页后签字盖章，扫描后重新上传
  2. 跟踪加急状态
  3. 补充、重新上传、生成材料

4. 操作流程#

第一步：【客户】进入项目#

在系统中打开目标项目，进入项目「加急通道」。若当前项目尚未付加急费用，则会看到“支付加急通道”入口。

第二步：【客户】发起加急支付#

点击“立即支付加急费用”，系统将生成对应支付链接。支付页面为支付宝支付链接，用户需要完成实际付款。

注意：

  • 生成支付链接并不代表支付已经完成
  • 用户完成支付后，需要在页面中点击“刷新支付状态”以确认支付结果
  • 只有后台同步确认订单已完成，页面才会显示为“已支付”

第三步：【客户】准备申请材料#

在加急页面中，用户可以查看并管理以下材料：

  • （学校件）学校申请需提供大学名称
  • 源代码文档
  • 使用手册
  • 设计文档
  • 帮助文档
  • 附加材料（补充真实研发材料或生成式声明等情况）

如项目已有材料，可直接上传到对应文档入口；如缺少材料，可在软宝宝生成或上传。

第四步：【软宝宝客服】材料预审#

客服将材料提交给系统预审：

  • 预审通过：客服生成签章页，并上传至软宝宝，等待客户签字盖章。
  • 预审不通过：客服通知用户更新材料；收到新材料后，重新进行预审。

第五步：【客户】签章页签字盖章#

客户从软宝宝下载签章页，按要求签字盖章，然后上传。

第六步：【软宝宝客服】缴纳官费和提交材料#

客服为项目缴纳官费，然后将预审通过的材料和客户签字盖章的签章页，通过加急通道提交给版权局。

第七步：【版权局】受理审查#

以下为加急通道各环节处理时间的大致估计：

  1. 客服提交到版权局后，申请状态为「提交」；
  2. 大约 7 天后，状态变为「受理」；
  3. 转为「受理」后，约 3 周转变为「审查通过」或「补正」；
  4. 「审查通过」到下证（收到软著电子版）约 1 周；
  5. 若为「补正」，需在 30 天内提交新/补充材料；材料提交后状态回到「提交」（返回第 1 步）。

如果受理不通过：

  • 受理结果为「非正常理由」（例如“建议撤回”）时，加急终止，客服撤回申请并触发退款；
  • 受理结果为「正常理由」（例如“模板化程度高”“通用性高”等）时，客服将联系用户补充或更新材料并重新提交。

第八步：【客户】等待收到软著电子版#

客服会定期追踪并更新版权局的状态到软宝宝。一旦下证，客服会将电子版上传到软宝宝，供客户下载。

5. 补正与退款#

补正的情况比较复杂，软宝宝客服会根据收到的补正理由进行判断。基本原则如下：

  • 若补正理由属于需要更新、补充材料的「正常理由」（例如“模板化程度高”等），客服会联系客户补充材料，并协助重新提交。两次补正的重新提交均不额外收费。
  • 若两次补正仍未通过，客服需从版权局撤回申请并向系统申请退款。软宝宝在收到系统退款后，会退回官费（￥600）给客户；渠道和服务费（￥70）不予退回。
  • 若补正理由为“建议撤回”等非正常理由，客服需撤回申请并向系统申请退款，退款金额和流程同上。
  • 若客户错过 30 天补正期限未提交补充材料，或主动放弃补正，视为客户放弃该项目的加急权益，相关费用不予退还。
  • 若客户已支付加急费但客服尚未提交预审，可申请全额退款（￥670）。
  • 系统从申请退款到软宝宝收到退款，通常需要2个月左右。

6. 常见问题#

Q：为什么支付链接返回后页面还没有显示“已支付”？#

因为支付链接只是创建了支付入口，尚未确认实际支付成功。用户需要在支付页面完成付款，并通过“刷新支付状态”确认订单是否已完成。

Q：什么时候需要上传签章页？#

通常在项目材料准备完成、加急流程进入提交阶段后，需要上传签章页。具体要求以后台通知和项目流程为准。

Q：加急费用是否包含材料重新生成？#

不包含。加急费用仅覆盖加急通道服务与相应官费；若需要补充或重新生成材料，通常需要单独处理对应服务。

Q: 怎样联系软宝宝客服？#

可以在 联系方式页面 扫描二维码，联系官方客服。也可以在 设置页面，留下您的联系方式，方便客服直接联系您。

7. 说明#

  • 加急通道是为了支持高优先级申请流程，不改变版权保护中心的审核标准。
  • 申请材料仍需符合官方规范和要求。
  • 若材料存在问题，仍可能出现补正或审核驳回的情况。

如果您已经具备项目材料并希望尽快推进申请，可在项目页面中进入“加急通道”进行操作；如需进一步协助，请通过页面底部联系入口联系工作人员。
