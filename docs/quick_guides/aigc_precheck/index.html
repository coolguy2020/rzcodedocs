AIGC 预检查是什么？#

AIGC 预检查是软宝宝提供的智能代码分析工具，可自动扫描您的源代码文档，检测其中常见的 AIGC（人工智能生成内容）特征与风险，帮助您：

  • 提前发现风险 — 在提交软著申请前，识别代码中可能存在的 AIGC 生成特征
  • 了解审查重点 — 获得具体的风险提示与严重程度评估，重点关注高风险部分
  • 优化申请材料 — 根据检测结果修改代码或提供补充说明，增强申请说服力
  • 降低审查风险 — 主动排查问题，减少软著申请被驳回或补正的可能性

重要说明#

AIGC 预检查是非官方指导服务，基于我们的过往大量服务经验的总结，旨在帮助降低 AIGC 相关风险。

  • 预检查通过不代表软著申请一定不会被 AIGC 补正
  • 预检查未发现特征不代表代码完全不存在 AIGC 生成迹象
  • 预检查结果仅供参考，不构成对申请结果的承诺或保证

您应对最终提交的材料合法性、真实性承担最终责任。

如何启用 AIGC 预检查#

第一步：登录并选择项目#

  1. 登录 软宝宝
  2. 点击左侧菜单选择或创建项目
  3. 进入项目详情页面

第二步：进入 AIGC 预检#

  1. 进入到 Part A 源代码文档
  2. 点击 AIGC 预检 卡片中的"开始 AIGC 预检"按钮
  3. 或点击卡片上的"预检"链接

【可选】第三步：上传源代码文档#

您可以直接对软宝宝生成的源代码文档进行预检，也可以按照下面步骤上传本地的源代码文档进行预检。

  1. 点击 上传源代码文档 按钮
  2. 选择本地 .docx 格式的源代码文档（需与申请材料一致）
  3. 等待上传完成

第四步：启动预检查任务#

  1. 确认您的剩余 credits 充足（预检查固定消耗 3.6 credits）
  2. 点击 开始 AIGC 预检 按钮
  3. 任务提交后将在后台异步处理，您可以关闭页面，任务进度不受影响

第五步：查看预检查报告#

  1. 任务完成后，点击 下载 AIGC 预检报告 按钮
  2. 获得 Word 格式的详细预检查报告
  3. 报告基于 6 项检测规则的分析结果与建议

预检查的工作原理#

AIGC 预检查基于以下 6 项检测规则，采用 AI 驱动的深度分析引擎。每项规则都会独立执行一次 LLM 调用，从不同维度检测代码的真实性与风险：

规则检测内容优先级
规则 1AI 偏好语言风格P1
规则 2非真实开发信号P0
规则 3注释质量P1
规则 4逻辑实现质量P1
规则 5逻辑缺陷P0
规则 6AI 思考链路残留P0

检测优先级说明#

  • P0（优先级最高）：规则 2、5、6 包含最强 AIGC 证据（非真实开发、硬编码密钥、AI 思考残留）。P0 级发现任何一处即可被判定为"confirmed"（高置信告警）。

  • P1（优先级中等）：规则 1、3、4 检测 AI 生成代码的常见但不绝对的特征。单个发现为"downgraded"（低置信疑似），需人工进一步确认。

预检查报告如何使用#

预检查报告包含：

1. 整体风险评估#

  • 风险等级汇总（低风险 / 中风险 / 高风险）
  • 检测到的关键问题统计

2. 规则级检测结果#

  • 每项规则的单独分析结果
  • 具体的风险描述与严重程度
  • 关键问题所在的代码位置（函数名、内容等）

3. 优先级建议#

  • 风险提示按优先级排序，重点问题优先列出
  • 建议您首先关注高严重程度的问题

4. 如何应对#

若发现高风险问题：

  • 检查相关代码是否真实有效、符合开发逻辑
  • 考虑修改或重新实现存在问题的部分
  • 为高风险代码编写详细的功能说明或技术注释

若发现中低风险问题：

  • 评估是否确实需要修改
  • 可在申请时提供补充说明或技术文档
  • 解释代码的实际功能与业务背景

常见问题#

预检查需要多长时间？#

通常需要数分钟，取决于源代码文档的大小与复杂度。任务在后台处理，您可以关闭页面继续其他工作。

如果预检查通过，是否保证软著申请不会被驳回？#

不保证。预检查通过只说明在我们的检测规则范围内未发现已知特征。实际软著审查有更多维度，建议结合官方指导和专业意见。

预检查报告未发现问题是否代表代码完全不存在 AIGC 问题？#

不代表。预检查的检测规则基于过往经验总结，可能存在覆盖不到的情况。您应自行确保代码的真实性与合法性。

可以对同一个项目多次启动预检查吗？#

可以。每次修改代码后都可以重新启动预检查。每次运行都会消耗 3.6 credits。

预检查失败了怎么办？#

若预检查任务失败：

  1. 检查错误信息提示
  2. 确保上传的是有效的 .docx 格式源代码文档
  3. 尝试重新上传或修改源代码文档后重新运行
  4. 若问题持续，请联系客服
